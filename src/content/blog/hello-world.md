머릿속에만 두면 3개월 뒤엔 반드시 잊어버립니다. 검색해서 찾아낸 해결책도, 문서를 읽고 겨우 이해한
개념도 마찬가지였습니다. 그래서 남기기로 했습니다.

## 무엇으로 만들었나

- **Astro** — 마크다운으로 글을 쓰면 정적 HTML로 빌드해 줍니다. 기본 상태에서 클라이언트 JS가
  거의 0에 가까워서 페이지가 아주 가볍습니다.
- **GitHub Pages** — 무료 호스팅. `main` 브랜치에 push하면 GitHub Actions가 빌드해서 배포합니다.
- **Pretendard** — 한글 가독성을 위한 웹폰트.

## 어떻게 굴러가나

글 하나가 마크다운 파일 하나입니다. `src/content/blog/` 아래에 `.md` 파일을 만들고 push하면 끝입니다.

```bash
git add .
git commit -m "새 글: 제목"
git push
```

push하면 Actions 워크플로가 돌면서 `npm run build`로 정적 파일을 만들고, 그 결과를 Pages에
올립니다. 보통 1~2분이면 반영됩니다.

## 앞으로 쓸 것

당장 거창한 계획은 없습니다. 다만 이런 것들을 남겨 두려고 합니다.

1. 에러 메시지 하나 붙잡고 씨름했던 기록
2. 새로 써 본 도구의 첫인상과 한 달 뒤의 평가
3. 문서를 읽다가 "아 이래서 이렇게 설계했구나" 싶었던 순간

잘 부탁드립니다.
